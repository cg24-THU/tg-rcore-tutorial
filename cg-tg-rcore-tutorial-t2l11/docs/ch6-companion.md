# Chapter 6 Companion

The default runnable target of `cg-tg-rcore-tutorial-t2l11` is chapter 8, because it is the richer learning endpoint of the task.

The package still bundles the chapter-6 SMP extension under `src/bin/ch6_smp/`, and `make run-ch6` switches the build script to package the chapter-6 user-space cases before launching that companion binary.
