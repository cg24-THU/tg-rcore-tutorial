# cg-tg-rcore-tutorial-t3l8-easy-fs

This crate contains the EasyFS variant used by the published `cg-tg-rcore-tutorial-t3l8` chapter-8 kernel snapshot.

It preserves the inode helpers needed by the chapter-8 release packaging and runtime paths. It is published as a support crate for the main chapter-8 release crate.
